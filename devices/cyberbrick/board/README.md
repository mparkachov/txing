# Cyberbrick Board Native Workers

Cyberbrick copies the unit board behavior onto Alpine Linux/aarch64 with
cyberbrick-owned private interfaces. The canonical behavior and ownership
boundaries remain in [the board component contract](../../../docs/components/board.md);
the Alpine ABI constraints are recorded in the Cyberbrick architecture docs.
